# ADR-0002：单一入口 main thread

- 状态：已接受
- 日期：2026-11-16

## 背景
用户需要管理多个 bot 的多个会话，但希望只面对一个 personal agent。

## 决策
所有交互只发生在 aut 的 main thread。MVP 不开放底层 session 的直接交互，只提供只读任务面板。
为降低指代歧义，main thread 支持：问题/澄清卡片点击、引用某条 task 消息回复（确定性路由）。

## 理由
单入口是 personal agent 的产品形态；卡片与引用回复以极低成本消除大部分路由歧义。

## 后果
"用户在说哪个任务"主要压在决策树上，`taskCandidates` 的描述质量（预计算相对时间、序号、"刚回复过你"）很关键。
