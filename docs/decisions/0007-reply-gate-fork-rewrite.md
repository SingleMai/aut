# ADR-0007：回包门槛 + fork 改写

- 状态：已接受
- 日期：2026-11-16

## 背景
worker 的报告常常过长、充满技术细节，直接推给用户体验差。DeepSeek super-agent 原型用代码强制 100 词上限，超限报错让模型重写。

## 决策
worker 回合结束后，reply-gate 树检查：长度 ≤200 中文字符 + Jev noul 可读性。不通过则 **fork** worker session 改写（最多 2 次），
不支持 fork 时新开临时 session 只给报告原文；仍不通过则截断并提示"详情见任务面板"。原文始终保存在 task 详情。

## 理由
fork 拥有完整上下文、知道什么重要，又不污染原 session；chief 无需生成任何内容。

## 后果
每次改写多一次模型调用与延迟；长度阈值与可读性阈值需按日志调优。
