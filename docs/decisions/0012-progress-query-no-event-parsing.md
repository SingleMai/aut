# ADR-0012：问进度不做事件流解析

- 状态：已接受
- 日期：2026-11-16

## 决策
- 状态类问题：用 aut 本就维护的任务数据（状态、bot、时间、待回答问题）模板作答，并提供结构化任务面板。
- 开放式问题：原生 fork 提问；不支持 fork 则新开临时 session 读取 transcript 作答。
- 不对 harness 事件流做程序化解析以推断"做到哪一步"。

## 理由
程序化解析脆弱且随 CLI 版本漂移；让模型读 transcript 回答更可靠。

## 后果
deep ask 有模型调用成本与秒级延迟，走异步，回答经 reply-gate。
