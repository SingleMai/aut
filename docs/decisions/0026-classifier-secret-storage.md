# ADR 0026：分类器密钥的本地保存

- 状态：已接受（用户确认采用独立本地文件）
- 日期：2026-11-16

## 背景

config.json 只保存 classifier.apiKeyRef，桌面设置页需要录入密钥。用户选择独立 0600 文件，
保持已有环境变量、CLI Provider 与项目配置。OpenMausBot 固定版本
738ec88472a3b888ff7b7793755d89da613ed301 的 server/config.ts:1006 使用 0600 原子文件保存；
aut 参考该机制与环境引用思路，未复制其代码，并继续将密钥与公开配置分离。

## 决策

- 密钥保存在 aut 数据目录的 secrets.json，默认 ~/.aut/secrets.json。aut 自身目录 0700，
  文件 0600；不修改现有父目录权限。拒绝符号链接和非普通文件。
- 文件采用 Schema 验证的 `{ schemaVersion:1, entries:[{name,key}] }`，名称唯一；
  name 为 1–64 个 ASCII 字母、数字、下划线或短横线，首字符必须是字母或数字。
  同名保存替换该条密钥，不影响其它条目。损坏文件明确失败，不用空文件覆盖。
  文件读写均限制在 1 MiB，拒绝会超出可读取上限的保存并保留上一份文件。
- 使用同目录随机临时文件、0600 排他创建、文件 fsync、原子 rename、目录 fsync；
  daemon 内串行读改写，已有进程所有权锁禁止同目录双实例。
- `secret:<name>` 明确引用本地密钥。`env:NAME` 与既有裸环境变量名继续支持，
  未设置引用时默认 env:TYPESAFE_API_KEY；显式引用决定来源，不改写环境或 Provider。
- 内部使用 Effect Redacted 包装。HTTP 仅允许保存与配置状态查询，不提供密钥读回；
  解析、文件系统和验证错误不携带密钥原文，密钥不进入普通配置、日志或报告。
- 设置页使用密码输入，保存成功后清空输入、将引用填入所选分类器字段；
  用户保存全部设置后应用该引用。不自动请求外部服务验证密钥。

## 后果

文件中的密钥以明文存于当前用户可读取的本地文件；备份数据目录会包含密钥。
本方案无 Keychain 依赖，可由独立打包的 daemon 使用。Provider 与已有设置保持不变。
