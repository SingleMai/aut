# ADR-0036：直接复用 OpenMausBot 工具展示组件与规则

- 状态：已接受（用户明确要求交互 1:1 还原，并优先直接复制代码）
- 日期：2026-11-17
- 窗口与复用组件的挂载方式已由 [ADR-0044](0044-desktop-react-renderer.md) 更新。
- 样式类、主题与样式构建已由 [ADR-0050](0050-unified-desktop-styles.md) 更新。

## 背景

ADR-0035 接通了原生工作会话，但手写 DOM 版本只参考了可折叠外观，遗漏了上游的
Simple 命名、连续成功工具聚合、完成回合折叠、失败原因摘要和工具可见性/定位规则。
用户明确要求直接继承这些规则；本决策替代 ADR-0035 中工具区域坚持原生 DOM 实现的选择。

## 决策

1. 固定 OpenMausBot `738ec88472a3b888ff7b7793755d89da613ed301`，直接复制 Apache-2.0
   范围的 `ToolActivity`、`ActivityRun`、`TurnNarrationRun`、所需纯函数及对应回归测试。
   `apps/desktop/src/openmausbot/` 保存来源文件；保留原算法、React 状态逻辑和样式类。
   导入、最小视图类型、中文语言资源及 API 入口通过适配层连接，文件头及 NOTICE 记录来源和修改。
2. 任务会话正文使用局部 React 根，沿用上游组件；其余 Electron/DOM 客户端不重构。
   React/样式构建依赖采用上游锁定版本；Tailwind 只为该区域生成样式，不加载全局 preflight。
   UI 状态仅包括折叠、显示偏好和定位；任务、请求、队列及会话数据仍只来自 daemon。
3. 展示前将 `SessionHistory` 投影为组件需要的 Message/Tool 视图数据，既有 API 不修改。
   运行与成功必须依据真实状态；unknown/interrupted 不冒充成功。命令、文件和 MCP 的名称/输入/输出
   映射遵循上游 Codex 投影；失败摘要只采用记录中明确提供的原因，不生成或猜测原因。
4. 直接使用上游 `groupTranscript`：成功的连续步骤聚合；有最终回答时只折叠同回合的成功工具，
   助手进度、最终结果和非成功步骤保留在外。不再把旧回合的全部内容收进“之前 N 轮”。
5. 默认 Simple 易读标签，提供 Advanced 和工具显示开关；保留定位记录时展开所属组的行为。
   新偏好只影响本地显示，不发送消息、回答问题或改变执行。
6. 保留上游完整输出懒读组件逻辑与失败重试测试。aut 当前 API 返回完整工具输出，投影不设置 clipped；
   因而生产路径无需另发完整输出请求，不虚构裁剪状态，也不为 UI 改造新增业务协议。
   唯一语义文案覆写是 previewHint：改为“工具输入与输出记录，分享前请先检查。”，
   不沿用上游“已缩短并自动屏蔽”的提示来错误描述 aut 的完整记录。
7. 以同一组 fixture 比较直接复制的上游规则输出和实际组件行为；迁入上游相关测试，并做真实 API/WS
   界面验收。不能用项目测试总数代替上游行为一致性证据。

## 边界与后果

不复制 enterprise，不 fork 整个应用；chief、唯一主会话输入、权限、问答和持久化语义不变。
1:1 验收范围是这组三个工具组件及其分组/命名/状态交互，中文翻译及 aut 数据入口属于明确适配项。
上游独有的团队账户、远程设备和服务 API 不导入 aut；缺少的数据不伪造。
局部增加 React 和编译样式依赖，换取直接沿用组件及后续可追踪的上游差异。
