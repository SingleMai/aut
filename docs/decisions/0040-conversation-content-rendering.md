# ADR-0040：复用 OpenMausBot 对话正文，同时保留本地窗口边界

状态：采用。承接用户要求按固定版本还原交互的决定，细化 ADR-0025 的正文呈现方式。

## 背景

原客户端用 `textContent` 显示全部回复，表格、代码围栏和标题会以标记原文出现。工作会话与主会话对同一条回复需要一致的阅读体验。

## 决策

- 助手正文使用 OpenMausBot 固定版本（同 ADR-0036）的 Markdown 展示代码，用户消息保留字面文本。长用户消息、代码折行和复制属于本地显示交互。
- 仅由受控组件创建元素并渲染转义后的文本，不解析原始 HTML，不加载正文图片，不允许消息内容打开应用窗口、外部程序或导航。HTTP(S) 地址只能由读者明确复制。工具输入输出仍按原始记录显示。
- 任务视图共享并在本地保存详细模式和工具可见性，只存显示选项。问题长文本复用上游组件；后续 ADR-0041 单独规定了已确认答案的只读回看。

## 后果

可沿用上游对话排版，不增加 IPC 能力或改变消息、答案的存储和投递协议。浏览器链接、附件预览以及已答原文回看不在此次实现范围。
