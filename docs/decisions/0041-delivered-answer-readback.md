# ADR-0041：确认投递后的只读答案回看

状态：已接受（用户确认）。

## 背景

已答卡只显示问题和状态，用户无法核对曾经提交的选项或文字。

## 决策

仅本地已认证的单请求读取接口在原生 question 的持久化 answerClaim.phase 为 delivered 时返回可选 deliveredAnswer。内容取自该次 claim，不从草稿、日志或消息推断。其他阶段及无 claim 的记录不返回此字段，不扩大列表、事件或日志输出。已答卡按原题和选项标签只读展示，不能编辑、重新选择或提交。未确认的状态沿用既有投递规则。

## 后果

刷新后可再次核对已确认的答案；旧记录缺少依据时只显示状态。此变更只增加查询投影，不改变投递、重试或任务状态机。
