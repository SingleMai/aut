# ADR-0044 桌面窗口统一使用 React

状态为已接受，2026-11-18。用户确认将桌面外壳和全部页面迁入 React。

## 背景

ADR-0025 采用原生 DOM 搭建窗口。ADR-0036 为复用工具记录的分组、折叠和展示偏好引入局部 React 根，ADR-0040 又将同一套正文组件用于主会话。窗口入口同时管理 DOM 缓存、组件挂载、页面刷新和焦点，修改一个交互需要跨两套生命周期。

## 决策与理由

每个桌面窗口在入口创建一个 React 根。外壳、主会话、任务、Bot 和设置各自由组件渲染，复用现有会话正文与工具组件。稳定的消息、任务和请求 ID 标识组件及其视图状态。回读使用现有的 Effect 客户端和 daemon 失效通知。组件的 ref 和清理函数负责焦点、滚动、原生对话框及订阅。

## 后果

React 负责视图生命周期，daemon 持有业务事实。验收覆盖草稿与中文输入法、历史分页的阅读锚点、原生题组的显式提交、任务工具展开、设置表单和页面往返。此决定更新 ADR-0025 的渲染技术和 ADR-0036 的局部根范围。
