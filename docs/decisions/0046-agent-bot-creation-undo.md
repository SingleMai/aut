# ADR-0046 在主会话撤销 Agent 创建的 Bot

状态为已接受，2026-11-18。

## 背景

工作 Agent 和慢脑都可以按 ADR-0045 创建普通 Bot。OpenMausBot 在会话里保留创建回执，用户可以就地撤销尚未修改、尚未使用的新 Bot。aut 原先需要用户去 Bot 页手动删除。

## 决策与理由

- 会话工具创建成功即在主会话保存一条来源任务可追溯的模板回执。用户通过回执的消息 ID 撤销这一次创建。手动创建继续走 Bot 页。
- 仅当配置仍与创建时一致且未登记过任务时，撤销才移除该 Bot 的配置。修改配置、使用 Bot 或从管理页删除都会结束这张回执的撤销资格。重复撤销同一张已撤销回执返回原结果，之后复用同一 Bot ID 的配置有独立身份。
- SQLite 记录创建身份、配置摘要和正在执行的操作。配置仍由现有服务原子写入 `bots.json`。daemon 启动时按实际文件结果恢复回执。任务登记和撤销在同一个 SQLite 写入排序点检查 Bot，先成功的一方决定结果。

## 后果

用户可以从对话中看到可撤销、已撤销或失效原因。旧消息和已有 Bot 使用原格式。手动建 Bot、工作 Agent 建 Bot、慢脑建 Bot 的授权沿用 ADR-0045。
