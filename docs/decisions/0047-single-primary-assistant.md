# ADR-0047 一个内置主助手，由任务来源决定协调权限

状态：单主助手设计已接受。下文的开发版升级方案与协议字段已由 [ADR-0048](0048-pre-release-data-baseline.md) 取代。

## 背景

ADR-0008 和 ADR-0033 分别为通用工作和慢脑协调预置了 Bot。两者使用相同的 Bot 配置和工作会话，用户却在设置里看到两个助手。新安装应当能由一个助手独立完成工作，也能在主会话里讨论、分工。

## 决策

- 只预置一个名为 aut 的主助手，以 `system: "primary"` 识别，ID 可变。用户和 Agent 均可按需创建专长助手。
- 主助手与专长助手一起参与普通路由，并承担通用兜底。明确的专长任务可直接派发。决策树的 `slow` 节点会在同一个主助手上登记协调任务。普通工作和协调各有自己的任务与原生会话。
- 只有主助手的协调任务可用 `propose_route`。会话注册、MCP 调用及 chief 登记提议时均按 Bot 身份与持久化任务来源核验。两种会话都可以亲自工作、提问或创建普通 Bot。
- 初稿为开发阶段的双助手配置设计过升级路径。该条已由 [ADR-0048](0048-pre-release-data-baseline.md) 取代。

## 后果

主助手既能独立完成工作，也能与用户讨论并提议分工。chief 仍按决策树串行登记派发。当前配置、会话角色和权限见[内置主助手](../primary-assistant.md)。
