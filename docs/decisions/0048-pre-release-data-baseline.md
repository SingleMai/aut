# ADR-0048 首次发布前使用单一数据格式

状态为已接受。

## 背景

aut 尚未向用户发布。早期开发数据包含双内置助手、缺少执行登记的会话和数版 SQLite 表结构。这些实验格式已完成验证用途。

## 决策

- Bot 配置只有一个可选系统标记 `primary`。所有已配置的 Bot 都参与路由。主助手 ID 写入入站状态的 `primaryBotId`，澄清卡保存用户可选的完整操作。
- `slow` 节点为主助手登记来源为 `coordination` 的任务，携带原决策 ID。该任务的 MCP 角色为 `coordinator`，普通任务的 MCP 角色为 `worker`。Bot 身份、任务来源和会话角色分别校验。
- 空数据库一次性建立七张表和全部索引。当前格式使用新的 SQLite `user_version = 4`，同版本直接重开，遇到其他已写入的版本即返回错误。开发时可以用新的 `AUT_DATA_DIR` 启动。
- 注册任务时，在同一事务创建会话及其执行登记。公开的任务队列只展示已登记的待投递消息。重启、重试和恢复读取持久化的执行登记。

## 理由与后果

配置读取、派发和恢复各自只处理当前协议。首次启动和重启走同一份 Bot 配置，已有模型选择仍由用户的 Provider 提供。首次发布前的实验数据由开发者自行管理。历史 ADR 和原始探针样本保留其记录时的含义。
