# ADR-0049 桌面图标与主会话的品牌应用

2026-11-18，已采用。

工具记录与宿主的样式边界后续由 [ADR-0050](0050-unified-desktop-styles.md) 统一。

## 背景

ADR-0037 确定了单眼角色与字标。桌面仍使用临时字母头像，macOS 开发包使用 Electron 图标。原稿中的细眼线和三根短线在菜单大小容易粘连。

## 决策与理由

依据原稿建立一套矢量图形，字标、应用图标、主助手头像共用轮廓。为小尺寸单独调整眼部留白。桌面沿用 ADR-0034 的对话布局，把品牌色、排版与首次进入主会话的样式落在宿主界面。工具记录沿用 ADR-0036 的组件样式。

## 后果

角色绘制、尺寸和配色集中维护在[品牌规范](../brand.md)。macOS 打包取用同源图标。首次会话的示例可放入草稿，由用户编辑和发送。
