# ADR-0050 桌面使用统一的 aut 主题

2026-11-18，已采用。通用控件的实现已由 [ADR-0051](0051-desktop-component-library.md) 更新。

## 背景

主会话开始使用 aut 品牌后，同一张问题卡的外框和选项分别读取 aut 与 OpenMausBot Daylight 的颜色。调整焦点、按钮或字号需要同时维护两套类名和构建规则。

## 决策和理由

所有桌面控件使用原生 CSS，同一份主题变量提供画布、表面、文字、强调色、状态色、焦点、圆角、阴影和字体。组件使用按用途命名的小写连字符类，选中、禁用、展开等样式直接使用已有的原生或 ARIA 状态。按功能拆分源文件，构建后浏览器预览和 Electron 共用一份样式表和本地字体。

## 后果

此决定更新 ADR-0034、0036 和 0049 的视觉实现。OpenMausBot 的来源记录、交互与分组测试继续维护。与上游对照时检查可见内容、控件语义和交互，aut 自己验收配色、焦点、换行和窄窗口布局。主题入口见[品牌规范](../brand.md)。
