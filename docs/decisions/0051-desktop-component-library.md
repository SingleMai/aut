# ADR-0051 桌面通用控件优先使用 Radix Themes

2026-11-18，已采用。

## 背景

ADR-0050 统一了 aut 的主题。消息菜单、问题分页和编辑表单仍需要维护键盘导航、焦点、弹层位置和关闭行为。用户希望优先使用成熟组件，再调整品牌主题。

## 决策

桌面采用 Radix Themes。通用按钮、图标按钮、表单控件、菜单、对话框与标签页优先使用库组件。应用根和弹层共用浅色主题，品牌颜色、字体及圆角由桌面主题入口统一配置。会话分组、输入法发送规则和答复投递继续由产品组件负责。问题选项的方向键只移动焦点，明确激活选项才更新答案。

## 后果

此决定更新 ADR-0050 的通用控件实现。自定义 CSS 主要负责品牌和会话布局。桌面预览和 Electron 仍使用同一份本地样式表。验收覆盖菜单两种打开方式、弹窗焦点、表单提交和题组切换。[组件库文档](https://www.radix-ui.com/themes/docs/overview/getting-started)
