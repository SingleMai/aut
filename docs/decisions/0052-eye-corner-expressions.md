# ADR-0052 单眼角色在眼角表达会话状态

2026-11-19，已采用。

## 背景

单眼 `a` 在 Dock 和会话里都容易辨认。原稿的三笔常驻头顶，用户容易把它们看成头发。三版发问姿态对照后，选定了沿眼角重画的短问号。

## 决策与理由

固定标志取角色待命时的侧眼。会话中的墨点、问号、对勾和星光随真实事件出现。符号沿眼睑走势收笔，底点与眉缘之间留白，头部和笔画一起运动。问题等待期间保持静止，送达反馈取自原生问题的确认。状态文案继续提供完整含义。

## 后果

此决定更新 ADR-0049 的固定笔画和工作提示动效。桌面组件与 macOS 图标共用矢量母版，减少动态效果时显示相应定格。角色、适用位置及事件映射见[品牌规范](../brand.md)。
