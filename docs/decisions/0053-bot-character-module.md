# ADR-0053　Bot 形象与动作

## 背景

单眼 a 已有一套用户认可的眼角表情。用户希望为不同 Bot 选择形象，并让每个形象用自己的动作回应相同的会话事件。

## 决策

- 新增独立工作区包 `@aut/characters`。包提供形象注册表、React 播放器、内置形象与配套样式。每个形象提供稳定 ID、展示名、渲染器和短动作目录。渲染器可以使用 SVG、图片、精灵图或其他 React 支持的媒介。
- 共享待命、思考、等你回答三种持续状态，以及答案已送达、报告就绪两种单次动作。形象可以声明自己的附加状态与动作。每个播放器实例独立消费带事件标识的动作，结束后呈现最新持续状态。减少动态效果时保留可辨认的静态姿态。
- Bot 配置可存一个形象 ID。省略时，主助手使用单眼 a，普通 Bot 使用名字首字。客户端遇到未安装的 ID 时采用同样的回退，保留原配置以便恢复。历史会话按当前 Bot 形象显示，历史事件应静默恢复。
- 应用图标和字标属于 aut 品牌。Bot 编辑器由注册表生成选择与预览。会话负责从已有任务、消息与原生请求确定状态及事件，形象模块只负责呈现。

## 理由

动作语义可供不同的角色共享。例如单眼 a 贴在眼角的问号与纸鸟歪头关注，都能表达“等你回答”。业务层只需知道 Bot 在等待用户。保存稳定 ID 可让客户端独立加入新形象，同时继续读取已有配置。

## 后果

首次提供单眼 a 和纸鸟两种形象。新增形象或专属动作只需扩展角色包及注册目录。新增能由业务触发的场景时，还需在发生该事件的界面明确其触发时机。问答反馈仍以原生请求送达结果为准。
