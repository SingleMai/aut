# ADR-0054　桌面跟随系统外观

## 背景

ADR-0051 确立了 Radix Themes 与 aut 的语义颜色，首版使用浅色。用户希望应用跟随 macOS 外观，并能在加入新角色或调整表单时预览真实组件。

## 决策

- 桌面窗口实时跟随系统浅色和深色偏好。页面、Radix 弹层和原生控件共享外观，业务组件通过同一组语义变量取色。
- 开发预览提供独立入口，复用正式组件与合成问答样例。评审者可切换外观、宽度与减少动态效果。预览在本地运行，示例操作只改变页面内的状态。
- Bot 列表的头像和编辑按钮共用一个编辑器。头像入口聚焦已选形象。能归属到字段的校验错误在字段旁说明，提交后展开并定位到首个出错字段。

## 理由与后果

跟随系统符合 macOS 的阅读习惯。开发预览可在两种外观中直接复核会话业务状态、表单和角色的可辨识度。主题选择和预览操作均属于客户端呈现，无需更改 daemon 协议。该决定更新 ADR-0051 中对浅色外观的限定。
