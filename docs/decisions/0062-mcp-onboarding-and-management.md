# ADR-0062：MCP 粘贴接入与主助手管理

- 状态：已接受
- 日期：2026-11-23

## 背景

用户已确认继续对齐 OpenMausBot 的 MCP 接入体验：粘贴配置、测试连接、分配工具，并通过主会话管理。ADR-0061 的注册表和 supervisor 是唯一执行入口；现有触发器直接使用同一 Bot 授权，无需新增调度路径。

## 决策

1. 桌面新增粘贴导入入口，支持 URL、`claude mcp add` / `add-json`、常见 stdio 启动命令和 MCP JSON。解析不执行 shell，也不展开环境变量或命令替换。借用 OpenMausBot `src/lib/mcp-paste.ts` 的分词、占位符和命名规则，适配 Effect 错误与当前 Schema，标注来源并更新 NOTICE。
2. 导入先展示可编辑预览。环境变量和请求头使用密码字段；变量及占位符要求填写真实值。保存时通过现有 SecretStore 写入凭据，注册表只接收引用。名字冲突产生新名称，不覆盖已有 server。逐项保存、测试并报告结果；失败项保留可重试，已保存项不重复创建。测试成功后仍由用户开启 server 并选择 Bot 与具体工具，沿用 ADR-0061。
3. `mcp_info` 对合法会话开放，返回 server 的 ID、名称、传输、健康/认证状态、工具参数及授权摘要，不返回地址、启动参数、请求头或环境值。普通 Bot 仅见已分配给自身的 server；主助手可见全局配置与 Bot 列表。
4. `mcp_server` 对合法会话注册，但只有 `system: primary` 的主助手可执行写入（普通任务和协调任务均可）。支持新增、修改、测试、启停、重启、删除和精确工具授权，复用 supervisor；每次调用重新校验身份。主助手仅按用户明确要求更改配置/授权，不能自行扩大授权。凭据只接收 `secret:`/`env:` 引用，登录和凭据录入留在桌面；不确定写入不得自动重试，先用 `mcp_info` 核对。
5. proxy 的工具发现完整透传上游 JSON Schema；调用时在 daemon 再次校验当前 server、grant 和目录，不依赖注册时的授权快照。撤销授权、禁用、删除和退出登录立即阻止后续调用。配置变更关闭旧连接并清理应失效的 OAuth 凭据，下一次连接使用新参数。退出登录、删除、修改连接和重新登录后，旧登录回调或令牌刷新不得恢复失效凭据。新授权的工具从下一次会话注入生效。服务名 `aut` 保留给内置桥，所有新增和编辑入口统一拒绝。
6. 每条外部连接由独立 Scope 管理；连接/发现失败关闭资源并按退避时间限制重连，显式测试可立即重试。业务工具调用不自动重放。工具目录分页完整读取。

## 后果

- chief 决策树、Provider 配置、任务身份和触发器调度保持既定边界；模型只在已有 worker/协调会话中调用管理工具。
- 直接维护当前注册表格式，不增加旧 Bot 配置兼容或迁移。
- 验证覆盖真实 stdio proxy、撤权与重连、导入和主助手权限，并以隔离数据目录完成服务接入到计划任务的集成验收；第三方登录需要真实凭据，不能用合成测试冒充。
