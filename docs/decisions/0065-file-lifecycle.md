# ADR-0065：未发送附件回收与原生文件操作

- 状态：已接受（用户要求补全文件能力后统一体验）
- 日期：2026-11-24

## 背景

ADR-0064 已保存不可变输入和成果。需要补全移除草稿、关闭窗口及异常退出后的空间回收，并完成原生桌面交付。保留既有 MessageFiles、SQLite 消息引用与 Electron IPC 边界。

## 决策

1. 上传文件在独立 `draft.json` 中登记七天租期；成果文件不带草稿标记，永不进入自动回收。清单和内容格式不变，不引入迁移或兼容逻辑。保留 `metadata.json` 与 `draft.json` 为内部文件名。
2. renderer 每五分钟为仍在编辑的附件续期，移除附件和卸载输入框时请求释放；迟到上传若已被移除也释放。断线、刷新或崩溃无法释放时，由 daemon 启动及每小时回收过期草稿；七天前遗留的未完成上传目录一并清理。
3. SQLite 中任一主会话消息引用的文件始终保留，包括历史输入、排队请求和引用续聊。删除前查询引用，未知或损坏清单保守保留。引用查询只返回 ID，不载入整段会话。消息附件解析至消息事务提交期间，与释放/回收共享 MessageFiles 锁；统一先文件锁、后 Store 事务，防止“已提交消息指向已删除文件”。
4. 新增续期与释放 API，均沿用鉴权和文件 ID 边界。释放缺失文件幂等成功，已引用附件与成果返回未释放，绝不提供任意路径删除。客户端失败不妨碍继续编辑，后续周期继续续期。
5. 原生预览使用已安装 Electron 的 macOS `BrowserWindow.previewFile`，由窗口管理 Quick Look 生命周期。保存副本使用同目录临时文件和原子替换，失败保留原目标；拒绝保存到应用快照目录及其路径别名。Finder 定位仍只接收已验证文件 ID。

## 后果与验证

这是附件生命周期收尾，不增加新的路由、模型调用或会话入口。验证过期、续期、已引用保护、成果保护、重启、迟到上传及发送/删除竞争；使用隔离目录运行真实 Electron 安装包的上传、预览、保存/取消、Finder 和 Quick Look。用户现有数据目录及 Provider 配置不参与验收。
