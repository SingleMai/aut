# ADR-0072：个人远程执行主机

- 状态：已接受（实现与验收按本 ADR 分开记录）
- 日期：2026-11-25

## 背景

ADR-0071 的真实双机与换网复验通过，用户要求继续接入 aut。现有 daemon 已独立于桌面
进程运行；需要让远程桌面复用同一主会话、问题、文件与任务 API，并隔离两台设备的执行身份。

## 决策

1. 一个桌面一次选择本机或一台远程主机。远程模式不启动本机 daemon；离线、鉴权失败和
   主机身份不符均不回退本机。切换目标保存设置并重启桌面，清除旧主机的视图与草稿边界。
2. `packages/transport` 提供 Effect 服务与一个独立 Go/tsnet 子进程。Go 只处理节点登录、
   对端身份检查和固定目标 TCP 转发；不访问业务数据、Provider、主会话或 daemon token。
   TypeScript 用共享 Schema 校验启动配置和逐行事件，子进程绑定 Scope。
   这是 ADR-0009 的有限语言例外，业务逻辑仍统一使用 TypeScript / Effect。
3. Pro 在本机设置中主动开启远程主机。daemon 管理主机连接组件；关闭桌面、Air 退出或
   断线不影响 daemon。默认仍仅本地运行，不自动开启远程、不自动注册登录启动项或修改睡眠设置。
4. 本地 HTTP 继续只监听回环。主机组件在 tailnet 的固定端口转发到该 HTTP 端口；
   客户端组件只监听本机动态回环端口，按配对信息中的 Tailscale 稳定节点 ID 寻址并核对对端。
   保留已验证的按系统路由选择网卡设置；不修改 Clash、系统 DNS、代理或路由。
5. 远程使用独立的随机 256 位访问密钥，绝不分发 `daemon-token`。主机生成的连接信息包含
   协议版本、主机 ID/名称、Tailscale 稳定节点 ID 和远程密钥。仅本地鉴权可导出、关闭或轮换。
   第一版为个人所有者权限：持码客户端可使用现有业务 API，包括配置管理；不开放主机连接凭据管理。
   主机关闭或轮换时立即撤销旧凭据并关闭其既有实时连接。
6. Air 通过 Electron 主进程将连接信息以 `safeStorage` 加密保存。renderer 仅在用户粘贴时
   临时持有输入，正常状态不包含密钥。复制主机连接信息由主进程直接写剪贴板。
   登录仅打开组件返回的官方 HTTPS Tailscale 登录地址。
7. 桌面必须在远程离线或待登录时仍能显示连接设置。断线期间保留当前窗口的视图和草稿，
   显示执行主机及离线状态；不自动重放写操作。网络恢复后重建 WebSocket 并重新读取所有视图数据。
   普通消息重试复用既有稳定消息 ID；问答沿用已有投递状态，不推测或自动补答。
   首次启动时，本机服务初始化同样不得阻塞桌面连接设置；没有安装开发环境的 Air
   可直接粘贴 Pro 的连接信息。本机初始化失败显示错误，不覆盖其凭据、不自动换执行目标。
8. 远程成果通过既有文件 API 获取，在 Air 按主机 ID 和文件 ID 缓存并核对摘要。
   Quick Look、Finder 和另存为操作只使用 Air 的文件路径；不会把 Pro 的路径当成本机路径。
   第一版不转发任意开发端口、不挂载远端文件系统；动态网站预览另行设计。

## 理由

继续保留唯一执行主机及既有 daemon API，可以复用任务、问答与消息幂等语义。
独立连接组件处理 Go 原生 tsnet 的平台差异，TypeScript 保留凭据与业务边界。
第一版连接信息沿用已验证的两端登录与显式配对方式；设备级授权管理可在后续扩展。

## 后果与验收

生产连接状态、配置与 helper 事件定义见 `packages/protocol/src/remote.ts`；产品交互见
`docs/desktop.md`。须覆盖离线启动不派生本机服务、身份不符拒绝、凭据轮换/撤销、helper
退出与恢复、HTTP/WS 恢复后的快照、远程文件缓存及 UI 草稿保留。
测试使用隔离数据；真实 Air/Pro 登录、合盖与真实 harness 任务续跑必须独立记录，不能由模拟测试代替。

用户原有项目及 Provider 配置不迁移、不复制；在任一设备操作的都是当前选中主机上的业务数据。
