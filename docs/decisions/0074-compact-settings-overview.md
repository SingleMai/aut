# ADR-0074：紧凑设置总览

- 状态：已接受
- 日期：2026-11-25

## 背景

用户认为 ADR-0073 的设置分类难以理解，双层侧栏和大块引导卡片增加了界面负担。
个人客户端应直接呈现正在使用的电脑和已配置的 AI 工具，工程模块不作为日常导航。

## 决策

1. 设置采用单列总览，移除独立设置侧栏。「设备」集中展示当前工作电脑、连接其他电脑及
   允许其他设备连接本机的开关；本机开启后的登录和复制操作在原位置按状态显示。
2. 「AI 服务」按实际配置名称（例如 Codex）展示紧凑条目，点击展开编辑。
   ID、命令参数、环境变量保持在次级字段中；消息分类服务放在「高级」内，说明其自动分配用途。
   不将「执行器」「消息路由」「执行配置」作为用户导航。
3. 表单折叠只改变显示状态。编辑草稿保留，校验失败自动展开并聚焦相应字段。
   所有 AI 配置继续保存到当前工作电脑，并在配置区明确说明。
4. 配对仍使用 ADR-0073 的独立弹窗、主进程暂存与确认流程。更换连接码、关闭远程访问仍需
   展示已有连接受影响的说明；网络、凭据、配置协议和保存行为不变。

本 ADR 取代 ADR-0073 的设置导航和主机大卡片呈现方式，不改变其配对边界。

## 验收

检查本地、远程待登录、断线及本机服务不可用时的设置入口；验证折叠表单的草稿与错误定位。
使用示例数据检查浅/深色与窗口最小尺寸。不得将界面截图中的连接状态视作真实双机验证。
