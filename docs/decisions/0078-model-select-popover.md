# ADR-0078：模型选择器使用独立浮层

- 状态：已接受
- 日期：2026-11-26

## 背景

ADR-0077 的三栏已经接入 Bot，但入口和弹层都铺满编辑框，底部另有确认栏，视觉上像
嵌套配置面板。依赖输入框下方剩余高度还会在较小窗口内压缩模型和参数列表。
用户明确要求整理成 select 浮层。

## 决策

1. 入口改为紧凑的单行选择框，展示当前模型和参数摘要。
2. 继续使用 Radix Popover 的 Portal、关闭和焦点管理。浮层相对触发控件定位，尺寸按
   整个窗口约束，可以越出 Bot 编辑框；上下均放不下时，像原生 select 一样覆盖触发区域，
   不将浮层压缩到编辑框内部。窗口变化和滚动后重新定位。
3. 保留 provider / 模型 / 参数三栏和顶部搜索。减少重复标题、正向状态标签和边框，
   移除底部模型摘要与「完成」栏。点击外部、Esc 或顶部关闭按钮只收起选择浮层，不关闭
   Bot 编辑器；浮层打开时管理自身焦点和外部指针事件。选择写入 Bot 草稿，
   仍由 Bot 的保存按钮持久化；模型能力、配置保护和失败处理沿用 ADR-0077。

## 后果

不改变模型目录、协议或执行行为。验收重点为越出父编辑框但保持在窗口内、列表滚动、
深浅色、键盘焦点、关闭与取消语义；使用实际渲染器和隔离示例数据检查。
