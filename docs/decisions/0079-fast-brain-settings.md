# ADR-0079：在设置中选择快脑模型

服务来源与可选备用的最新交互见 [ADR-0080](0080-fast-brain-routing-failure.md)。

## 背景

主会话需要快脑判断一句话该交给哪个 Bot、是否接着已有任务处理。设置页原先把这项配置放在「高级」内，要求用户填写后端名称、模型和地址。用户希望直接看见快脑以及可用的服务来源。

## 决策

1. 设置总览显示「快脑模型」和已保存的主服务。展开后可选择「Jev 官方」「自定义服务」或「停用」。官方预填模型版本和服务地址，自定义服务使用现有的 Jev System One 请求与响应协议。
2. 「备用快脑」默认收起，使用相同的服务选项。主服务调用失败且决策节点仍有时间时，才尝试已配置的备用服务。详细行为见[决策树](../decision-tree.md#4-阈值与降级)。
3. 选择保存在当前执行电脑的既有分类器配置中。相同服务沿用已保存的地址、模型版本及密钥引用。新的自定义服务地址使用独立的密钥引用，也可显式指定环境变量。旧的未适配配置显式标出，直到用户选择替换或停用。Bot 的执行模型继续在 Bot 编辑器选择。

## 理由与后果

用户可以直接使用官方预设，也可以填写自己运行的兼容服务。设置页与实际调用共用模型版本和地址校验。现有分类器存储格式、决策树和密钥写入方式沿用原有实现。
