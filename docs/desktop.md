# 桌面客户端

`apps/desktop` 是 daemon 的本地 API 客户端（ADR-0025）。紧凑双栏和会话交互沿用 OpenMausBot Simple。通用控件使用 Radix Themes，主题入口见[品牌规范](brand.md)。
窗口使用一个 React 根渲染外壳、主会话、任务、Bot 和设置页。Effect 客户端负责 API 读写与校验，组件保存草稿、焦点、展开等显示状态。渲染边界见 [ADR-0044](decisions/0044-desktop-react-renderer.md)。

主会话与工作会话共用 OpenMausBot 的气泡分组和时间分隔规则。主会话还采用其引用预览、发送键、阅读位置和问题输入组件。aut 提供任务与发言人边界、原生选项 ID 和投递状态。逐文件上游来源见 [NOTICE](../NOTICE)。

## 开发和打包

在仓库根目录执行 `pnpm build`，然后按用途选择入口。

| 用途 | 命令 | 运行结果 |
| --- | --- | --- |
| 启动桌面应用 | `pnpm --filter @aut/desktop start` | 打开 Electron，连接本地 daemon |
| 在浏览器联调完整桌面 | `pnpm --filter @aut/desktop preview` | 默认在 `127.0.0.1:5177` 展示同一界面，操作会提交给所连接的 daemon |
| 打包 macOS 应用 | `pnpm --filter @aut/desktop package:mac` | 开发包位于 `apps/desktop/dist/package`，发行范围见[验收结果](acceptance.md) |

桌面默认连接 `127.0.0.1:4317`。`AUT_DATA_DIR` 和 `AUT_PORT` 可指定隔离的数据目录与服务端口，`AUT_DESKTOP_PROFILE` 可指定 Electron 用户目录，`AUT_PREVIEW_PORT` 可指定浏览器联调端口。连接被拒绝时桌面会启动 daemon，鉴权或协议错误会直接显示。关闭窗口后 daemon 继续运行。

启动等待上限为 60 秒，Codex 配置发现上限为 30 秒。普通 API 请求限时 10 秒，原生会话读取在服务端限时 20 秒、客户端限时 30 秒。

macOS 开发包通过 LaunchServices 启动 daemon 时，保留进程已有的 PATH 搜索顺序，再补充用户的 `~/.local/bin` 和标准 Homebrew 目录。显式配置的实例命令及环境变量继续生效。

## 组件预览

运行 `pnpm --filter @aut/desktop preview:components` 后，打开终端输出的本地地址。需要离线文件时执行 `pnpm --filter @aut/desktop preview:components --build-only`，用浏览器打开生成的 `.artifacts/desktop-preview/aut-components.html`。

这里使用合成问答和配置草稿。可以切换浅色、深色、预览宽度和减少动态效果，查看待答、排队、已送达的卡片，试填服务地址，或选择角色播放短动作。刷新页面会重置示例。

问答样例由组件预览和隔离桌面验收脚本共用。表单复用设置页的模型、服务地址字段和 Effect Schema 校验。修改主题或角色后，可以在此核对真实控件与动作。[问答样例](../apps/desktop/src/preview/question-fixtures.ts) · [桌面验收说明](../spikes/desktop/README.md)

## 主会话

- 首次进入空会话时，角色、简短说明和三个示例帮助用户开始。点示例把完整请求填入输入框并聚焦，由用户编辑和发送。切换示例会替换上一个示例，已有手写草稿时在光标或选区插入。有消息后，同一列用于阅读和输入。字标、图标与配色见[品牌规范](brand.md)。
- 主会话是唯一发送入口。左侧沿用 OpenMausBot Simple 的搜索框与任务行，显示 Bot、任务状态和最近活动时间。侧栏按活动时间排列已载入的任务，可按标题或 Bot 搜索。Esc 关闭搜索并把焦点交回搜索按钮。
- 点「任务」在右侧打开上次选中的工作会话。首次进入会在列表载入后打开最近活动的任务。从消息打开来源任务时，会关闭搜索并定位对应任务行。来源任务超出当前列表时，按 ID 补读，后续刷新保留该行直到切换任务。
- 输入框随内容增高，有非空白草稿时才显示发送按钮；Enter 或 Ctrl/⌘+Enter 发送，Shift+Enter 换行，输入法组合期间不发送。Esc 清除引用，发送结果保留之后新输入的草稿。
- 在派发确认上点「纠正派发」可改派或撤销。改派将原始请求交给另一个 Bot 新建任务，保留原任务。撤销会取消原任务。
- 阅读历史时保持位置，回到最新后恢复跟随；主动分页保留可视锚点。
- 点击气泡侧边的「…」或右键点击正文可打开消息菜单。选中的文字和气泡内的交互控件保留原生右键行为。方向键、Home 和 End 移动菜单焦点，Esc 返回触发按钮，点击外部关闭。选「引用回复」后焦点进入主会话输入框。消息上的完整报告链接读取该次回包的原文。
- 助手正文使用安全 Markdown 展示，用户消息保留原文。简洁对话中的 Markdown 表格独立占一块，前后说明仍属于同一条消息。正文不执行 HTML、不加载图片或触发外部导航；HTTP(S) 地址供明确复制（ADR-0040）。
- 回包下方的来源列表保留原报告的完整 URL，点击条目复制；长来源不受正文截断影响。提取范围与上限见 [ADR-0063](decisions/0063-report-source-links.md)。

来源展示的隔离界面实录：[回包来源](assets/desktop/report-sources.png)。

文件输入与成果交付遵循 [ADR-0064](decisions/0064-message-files.md)：输入框支持选文件、拖放和粘贴截图，发送前可预览、移除；上传失败保留草稿供重试。消息下方显示不可变文件卡片，支持预览、另存为和 Finder 定位。引用成果继续修改时沿用原任务及原文件版本。

未发送附件的续期、移除释放和过期回收，以及历史文件保护，统一见 [ADR-0065](decisions/0065-file-lifecycle.md)。原生另存为采用原子替换，拒绝覆盖快照目录；Quick Look 由 Electron 窗口管理。macOS arm64 实包已验证保存/取消、Finder 目标和 Quick Look 打开/关闭，应用内文本预览实录见[文件预览](assets/desktop/message-files-native.png)，验证范围见[桌面探针](../spikes/desktop/README.md#文件生命周期与原生操作)。

## 问题卡

- 正等待用户作答的原生问题使用琥珀色细边和文字提示。答复进入投递流程后，卡片显示对应的投递状态。
- 单题单选点击即提交；多题逐题作答，全部完成后明确提交整组。无预选答案，未完成题组不能提交。
- 在选项间按方向键、Home 或 End 只移动焦点。点击选项或在其上按空格、Enter 才确认选择。
- 多题文字 Enter/「完成本题」只完成当前题；底部「继续回答」进入未答题，完成后变为「提交整组答案」。标签页支持方向键及 Home/End，自由文本随内容增高。
- 卡片从单请求接口读取投递状态。已登记、提交中、结果未知、已排队均默认禁重；只有已登记状态提供显式「重新提交」。HTTP 202 仅表示已接收，确认原生送达才显示已回答。
- 状态刷新保留未提交草稿。没有已登记答案的过期问题可补答，后端按任务状态决定是否转为后续消息；投递规则见 [原生问题链路](questions.md)。
- 已确认送达的单题直接回显答案；多题默认显示同一行摘要，可展开查看原题和完整答案。后来继续发言只淡化旧问题的未选项，不改变答题权限；缺少投递确认时只显示状态，不从草稿或日志补造答案（ADR-0041）。

## 工作会话

- 原生上下文状态沿用 OpenMausBot 的用量环与详情仪表，位于显示控件旁；展开可查看原生 token、窗口和最近整理状态。
  自动整理时显示进行中提示，完成后等待新读数再显示百分比；缺少窗口只显示 token，读取失败不保留为实时读数。
  不支持的执行器隐藏入口。没有手动压缩或清空上下文操作，详见 [ADR-0067](decisions/0067-native-context-status-ui.md)。
- 按回合展示委托、助手输出和可折叠工具；默认读取最新 10 轮，可加载更早回合。查看记录不恢复执行，交流与答题返回主会话。
- 简洁模式按可见行合并连续同一发言人的气泡；不同回合、可见工具及时间分隔保留边界。
- 顶部保留状态与取消、重试、恢复、归档；任务 ID、队列和最近报告收在任务信息中。
- 实时输出按稳定 ID 更新，保留展开、焦点和阅读位置。当前工作会话串行回读，读取过程中收到的多次刷新通知只触发一次补读。更早回合加载失败时保留已有内容。最新回合刷新后，只要分页游标仍有效，就可以重试原页。切换会话后只接纳当前会话的响应。
- 工具区域复用上游 React 组件与分组规则：结束回合仅折叠成功工具，进度、结果及失败步骤仍可见。显示偏好在本地共享保存；Simple/Advanced、工具可见性和定位的范围见 [工具展示对照](omb-tool-parity.md)。

## Bot 与设置

- 在 Bot 页手动创建，或在主会话委托 Agent 创建。两种入口的结果都进入同一 Bot 列表。
- Bot 页以「主助手」标识唯一内置助手 aut，其余助手按用户配置的名称和专长展示。
- Bot 卡片的「记忆」默认阅读核心记忆，知识库提供图谱/搜索列表和关联文档阅读，笔记使用独立入口。
  显式进入编辑后支持新建和保存；历史、删除/清空及自动整理管理使用次级入口，审查快照只读。
  切换文件、分区、快照或关闭前提示未保存修改，保存失败保留草稿；原生文件变更可主动刷新。
  目录和调度规范见 [Bot 记忆](memory.md)，[核心记忆](assets/desktop/memory-core-reading.png) 与
  [知识图谱](assets/desktop/memory-knowledge-graph.png) 的界面实录使用隔离示例数据。
- Agent 创建后，主会话的创建回执提供「撤销创建」。Bot 改过配置、接过任务或已被删除时，原回执显示对应原因。详见 [ADR-0046](decisions/0046-agent-bot-creation-undo.md)。
- 点击 Bot 头像或用键盘激活「更换形象」，编辑器会聚焦当前选项。名称、形象和擅长的工作放在一起，思考强度放在「高级设置」。保存后，Bot 列表和会话使用同一形象。角色预览从「等你回答」开始，也可连续试看思考、等待、送达和报告。[编辑器实录](assets/desktop/bot-characters.gif) · [形象接入指南](../packages/characters/README.md)
- Bot 编辑器也可配置 soul、工作目录、Harness 实例和模型。系统身份受保护，长表单的标题和操作始终可达。Bot 和设置表单都会保留保存失败时的输入，在字段旁显示校验提示，展开相应区域并聚焦首个错误。
- Bot 编辑器提供 MCP 服务与逐工具授权，创建和编辑均可选择。勾选先保存为表单草稿，点击「保存」后使用现有 Bot 与 grant API 顺序提交；取消不改授权。Bot 已保存而部分 grant 失败时保留编辑器、已创建的 Bot 身份与未完成草稿，重试不重复创建 Bot。服务的全局启停和登录仍在 MCP 服务页管理。
- MCP 服务页沿用 OpenMausBot 单列服务行，显示传输图标、地址、启停与登录状态，连接测试结果在当前行反馈。工具目录和 Bot 授权按需展开；支持搜索工具名与说明、全选当前目录的精确工具名及清空。共用的授权组件也用于 Bot 编辑器。
- MCP 新增和编辑共用迁入的编辑器：粘贴服务地址、启动命令或 JSON 自动识别，优先只显示缺失凭据；「连接细节」再展开传输、逐行启动参数、工作目录、请求头/环境变量和 OAuth。凭据采用可增删的密码行，已保存值留空保留，列表只显示凭据名称。保存后逐项测试，部分失败重试不重复创建服务；未确认的写入禁止重复提交。新服务仍默认停用，授权即时回读。来源映射见 [MCP 界面对照](mcp-ui-parity.md)，协议范围见 [ADR-0062](decisions/0062-mcp-onboarding-and-management.md)。
- 设置页管理 Harness 实例及主、备用分类服务，并说明用户消息会发送到所选服务。「保存密钥」写入本机凭据并填入引用，「保存全部设置」才应用实例与分类器配置。后端、模型和服务地址均留空时，该分类服务停用。[本地 API](local-api.md) · [ADR-0026](decisions/0026-classifier-secret-storage.md)
- 路由试验只展示分类概率，不派发任务；既有 Provider 配置保持不变。
