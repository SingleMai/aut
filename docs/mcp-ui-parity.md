# MCP 界面对照

用户要求优先复用 OpenMausBot 已有实现。界面基线固定为 Apache-2.0 源码 `619a6b7b22a8bf970416c7d9cbf4e8b3c5ba4ddc`（2026-11-24），不使用 `enterprise/`。服务与授权协议仍遵循 ADR-0061、ADR-0062。

| 上游组件 | aut 接入与要求 |
| --- | --- |
| `McpServersPanel.tsx` | 单列服务行、传输图标、独立启停/登录状态、地址摘要、测试结果就地显示、编辑/删除图标及开关。空列表提供明确接入入口；不再使用 Bot 卡片网格。 |
| `McpServerEditor.tsx` | 新增和编辑共用组件。粘贴自动识别、显示服务摘要，只展开缺失值；连接细节按需展开。手动参数每行一项，避免要求用户编写 JSON。 |
| `McpSecretRows.tsx`、`mcp-draft.ts` | 迁入键值行、整行粘贴、密码输入、已保存值留空保留、变量前后缀和逐行参数处理。I/O 经 aut Effect API，配置只存凭据引用。 |
| `bot-settings/AccessSection.tsx` 的 `McpServersCard`、`ConnectorToolsGrants` | 采用服务开关行、授权数量、展开/收起、工具名与描述搜索、工具说明和受限高度的列表。aut 的全选只选择当前目录的精确工具名，不引入通配符或默认全授权。 |

## 接入边界

只迁入本地 MCP 所需 UI、纯草稿函数和交互结构；上游团队、云端、应用目录、工具预算及其状态存储不接入。通用控件继续使用 Radix Themes，样式使用 aut 的主题变量。所有异步写入保留失败草稿，导入成功项不重复创建，保存结果未知时先回读核对。服务测试、OAuth 和启用使用现有 daemon。

## 验证

验证粘贴识别、缺失凭据、编辑保留/替换已存凭据、多个服务部分失败、取消、删除确认、工具检索及授权失败回滚；浏览器使用隔离 daemon 检查空态、已连接、未启用、需登录和连接错误，兼顾窄窗口与深浅主题。结果入口在 `docs/acceptance.md`。
